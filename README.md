# 저승공무원으로 취업했습니다!!! — 예고편

**연극시그 [큐프로덕션]** · 강유선 작 · **11월 15일(일) 서울 합정 서교생활문화센터**

**본 작품의 저작권은 원작자(작가)에게 있습니다.**

강유선 작 연극 「저승공무원으로 취업했습니다!!!」의 클레이 스톱모션 풍 코드 기반 예고편입니다. `index.html` 하나로 동작하며, 브라우저에서 열면 바로 재생됩니다.

| 확장판 예고편 | 5분 | 74컷 — 전체 장면, 커튼콜까지 |

## 연출
- **스톱모션**: 초당 8컷으로 끊어 움직이고, 카메라와 화면은 고정된 채 판지 디오라마 그림자와 노출 깜빡임, 종이 자막을 사용합니다.
- **배경**: 저승관리청 사망승인과(깜빡이는 명부 서랍장, 거꾸로 도는 시계, 흔들리는 청사초롱, 떠다니는 서류와 혼불), 큐프 장례식장 면접실, 삼도천이 보이는 인사과 회의실, 이승의 원룸, 저승행 4와 4분의 4번 승강장.
- **인물**: 2등신 클레이 인형 스타일. 7명 모두 의상과 행동(도장 찍기, 전화, 펄쩍 뛰기, 박수, 인사, 걷기 등)을 애니메이션으로 표현. 산 사람인 유내일만 피부가 따뜻하고 그림자가 집니다.
- **대사**: 내용을 추론할 수 있는 짧은 힌트만 자막으로, 행동은 지문으로 표시.
- **음향**: 대본의 음향 큐(밝은 음악, 수신 벨소리, 통화 발신음, 통화 종료음, 방송음, 도장, 서류, 암전)를 Web Audio로 실시간 합성. 장면 분위기에 따라 음악 무드(밝음·코믹·따뜻함·으스스함·긴장)가 전환됩니다.

## 저승관리청 삼부작 (흑백 애니메이션)
대사와 자막 없이 행동, 빛, 추상 이미지로만 진행하는 예술영화풍 단편입니다. `film.html`에서 바로 재생됩니다.
- 본편 「도장」 15분 · 프리퀄 「444」 5분 · 시퀄 「4444」 5분 · 인물 프리퀄 9편(연출·무대조연출 포함) 각 3분
- 무성판 / 대사판(합성 음성 + 절제된 자막) 두 버전. 음성 파일은 `voices/`에 있으며 배우 녹음으로 교체 가능
- 영상: Release `media`의 `film_*.mp4`, `char_*_3min.mp4` (대사판은 파일명 끝에 `_dialogue`)
- 시놉시스: [SYNOPSIS.md](SYNOPSIS.md)

## 영상 파일은 저장소에 두지 않습니다
렌더된 MP4는 커밋하지 않고 **Release `media`** 첨부 파일로만 배포합니다. 페이지의 다운로드 버튼은 모두 이 Release를 가리킵니다.

**영상을 만들거나 다시 만들기:** 저장소의 **Actions → 「영상 렌더 → Release」 → Run workflow**를 누르면 GitHub 서버에서 29개 영상(삼부작·인물 프리퀄 무성판/대사판, 예고편·릴스)을 병렬로 렌더링해 Release에 올립니다. 하나만 다시 만들 때는 입력칸에 `film main talk`, `teaser v1`처럼 적습니다.
- 렌더 스크립트: `scripts/render.py`
- 대사판 음성: `voices/*.mp3` (배우 녹음으로 같은 이름의 파일을 바꾸고 워크플로를 다시 실행하면 반영)


## 페이지 구성
- `index.html`: 모든 영상(예고편 3, 릴스 2, 삼부작 3, 인물 프리퀄 9)을 탭 없이 한 페이지에 펼친 상영 페이지. 영상은 Release `media`에서 재생됩니다.
- `teaser.html`: 예고편·릴스를 브라우저에서 직접 그리는 재생기 (렌더 원본)
- `film.html`: 흑백 애니메이션 재생기 (무성판/대사판 전환, 렌더 원본)
