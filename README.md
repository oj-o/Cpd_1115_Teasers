# 저승공무원으로 취업했습니다!!! — 예고편

**연극시그 [큐프로덕션]** · 강유선 작 · **11월 15일(일) 서울 합정 서교생활문화센터**

강유선 작 연극 「저승공무원으로 취업했습니다!!!」의 클레이 스톱모션 풍 코드 기반 예고편입니다. `index.html` 하나로 동작하며, 브라우저에서 열면 바로 재생됩니다.

| 버전 | 길이 | 구성 |
|---|---|---|
| 티저 | 1분 | 14컷 — 합격 전화, 장례식장 면접, 명부 속 내 이름, 계약서, 4,444년 |
| 메인 예고편 | 3분 | 41컷 — 1~9장 핵심 장면 서사 |
| 릴스 1 · 반전 | 15초 (9:16) | 취업 축하 → 명부 속 내 이름 → 카운트다운 |
| 릴스 2 · 저승 입사 | 15초 (9:16) | 합격 전화 → 장례식장 면접 → 4와 4분의 4번 승강장 → 계약서 → 퇴근해!! |
| 확장판 예고편 | 5분 | 74컷 — 전체 장면, 커튼콜까지 |

## 연출
- **스톱모션**: 초당 8컷으로 끊어 움직이고, 카메라와 화면은 고정된 채 판지 디오라마 그림자와 노출 깜빡임, 종이 자막을 사용합니다.
- **배경**: 저승관리청 사망승인과(깜빡이는 명부 서랍장, 거꾸로 도는 시계, 흔들리는 청사초롱, 떠다니는 서류와 혼불), 큐프 장례식장 면접실, 삼도천이 보이는 인사과 회의실, 이승의 원룸, 저승행 4와 4분의 4번 승강장.
- **인물**: 2등신 클레이 인형 스타일. 7명 모두 의상과 행동(도장 찍기, 전화, 펄쩍 뛰기, 박수, 인사, 걷기 등)을 애니메이션으로 표현. 산 사람인 유내일만 피부가 따뜻하고 그림자가 집니다.
- **대사**: 내용을 추론할 수 있는 짧은 힌트만 자막으로, 행동은 지문으로 표시.
- **음향**: 대본의 음향 큐(밝은 음악, 수신 벨소리, 통화 발신음, 통화 종료음, 방송음, 도장, 서류, 암전)를 Web Audio로 실시간 합성. 장면 분위기에 따라 음악 무드(밝음·코믹·따뜻함·으스스함·긴장)가 전환됩니다.
