# 저승공무원으로 취업했습니다!!! — 예고편

강유선 작 연극 「저승공무원으로 취업했습니다!!!」의 코드 기반 예고편입니다. `index.html` 하나로 동작하며, 브라우저에서 열면 바로 재생됩니다.

| 버전 | 길이 | 구성 |
|---|---|---|
| 티저 | 1분 | 14컷 — 합격 전화, 장례식장 면접, 명부 속 내 이름, 계약서, 4,444년 |
| 메인 예고편 | 3분 | 41컷 — 1~9장 핵심 장면 서사 |
| 확장판 예고편 | 5분 | 74컷 — 전체 장면, 커튼콜까지 |

## 연출
- **배경**: 저승관리청 사망승인과(깜빡이는 명부 서랍장, 거꾸로 도는 시계, 흔들리는 청사초롱, 떠다니는 서류와 혼불), 큐프 장례식장 면접실, 삼도천이 보이는 인사과 회의실, 이승의 원룸, 저승행 4와 4분의 4번 승강장.
- **인물**: 7명 모두 의상과 행동(도장 찍기, 전화, 펄쩍 뛰기, 박수, 인사, 걷기 등)을 애니메이션으로 표현. 산 사람인 유내일만 피부가 따뜻하고 그림자가 집니다.
- **대사**: 내용을 추론할 수 있는 짧은 힌트만 자막으로, 행동은 지문으로 표시.
- **음향**: 대본의 음향 큐(밝은 음악, 수신 벨소리, 통화 발신음, 통화 종료음, 방송음, 도장, 서류, 암전)를 Web Audio로 실시간 합성. 장면 분위기에 따라 음악 무드(밝음·코믹·따뜻함·으스스함·긴장)가 전환됩니다.

## 사용
- 스페이스바 재생/일시정지, 좌우 화살표 5초 이동, 컷 목록 클릭으로 해당 장면 이동.
- 영상 파일이 필요하면 전체 화면으로 재생하면서 화면 녹화하세요.
